# Jogo Educativo (POO)

Projeto simples em Java que implementa pequenos jogos em paradigma orientado a objetos.

## Descrição

Este trabalho reúne vários mini-jogos (ex.: jogo de dados, adivinhação, quiz educativo) e as classes de suporte para gerenciar itens e jogadores.

## Estrutura

- `Main.java` — Classe principal que inicia o jogo
- `Jogo.java`, `JogoAdivinhacao.java`, `JogoDado.java`, `QuizEducativo.java` — Classes de jogos
- `Jogador.java` — Representa o jogador
- `GerenciadorDados.java` — Gerencia persistência/entrada de dados
- `Item.java`, `ItemCosmetico.java`, `ItemVantagem.java` — Representação de itens

(Arquivos podem variar — compile todos os `.java` do diretório.)

## Requisitos

- Java JDK 8 ou superior

## Como compilar e executar

Abra um terminal no diretório do projeto e execute:

```bash
javac *.java
java Main
```

Siga as instruções exibidas no console para jogar.
